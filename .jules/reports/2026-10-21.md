# Sentinel Audit Finding - 2026-10-21

## Summary
ISO 8601 timestamps containing 'T' (e.g. `'2026-10-06T23:15:00.123Z'`) in console log entries caused `time.strptime(e['timestamp'][:19], '%Y-%m-%d %H:%M:%S')` to raise `ValueError` in `server.py` (`build_console_log_entries`), causing those log entries to fail timestamp sorting and fall back to `(1, 0)`.

## Evidence
- `server.py:634`:
  ```python
  def sort_key(e):
      try:
          return (0, -time.mktime(time.strptime(e['timestamp'][:19], '%Y-%m-%d %H:%M:%S')))
      except Exception:
          return (1, 0)
  ```
  Calling `time.strptime("2026-10-06T23:15:00", "%Y-%m-%d %H:%M:%S")` raises `ValueError: time data '2026-10-06T23:15:00' does not match format '%Y-%m-%d %H:%M:%S'`.

## Impact
Call logs and console entries with ISO 8601 timestamps failed chronological sorting, leading to incorrect log ordering in the dashboard console view.

## Suggested Fix
Replace `'T'` with a space in `e['timestamp'][:19]` prior to calling `time.strptime`:
```python
ts_str = e['timestamp'][:19].replace('T', ' ')
return (0, -time.mktime(time.strptime(ts_str, '%Y-%m-%d %H:%M:%S')))
```

## Confidence & Severity
- **Confidence**: High
- **Severity**: Low / Medium
