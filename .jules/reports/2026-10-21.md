# Sentinel Audit Report - 2026-10-21

## Summary
Audited the Nexus backend services for error handling, shape resilience, and edge case safety. Identified three instances across `hermes_gateway.py`, `visibility.py`, and `server.py` where JSON responses and persistent stores were assumed to be dictionaries without type validation, leading to unhandled `AttributeError: 'list' object has no attribute 'get'` when encountering top-level JSON arrays (`[...]`) or primitive payloads.

## Findings

### [High][Bug] Unhandled AttributeError on top-level JSON array in `hermes_gateway.py`
- **File & Line**: `hermes_gateway.py:67`
- **Impact**: Gateway proxy endpoints or custom models endpoints returning top-level JSON lists (`[{"id": ...}]`) cause `list_models()` (and consequently `catalog()` and `/api/live-providers`) to crash with `AttributeError: 'list' object has no attribute 'get'`.
- **Proof**:
  ```python
  with patch('hermes_gateway._get', return_value=[{'id': 'gpt-4o'}]):
      hermes_gateway.list_models(force=True)
  # Crashes with: AttributeError: 'list' object has no attribute 'get'
  ```
- **Fix**: Parse `/models` responses using `models_payload.model_rows(data)` to safely normalize both dict (`{"data": [...]}`) and top-level list (`[...]`) catalog responses.

### [Medium][Bug] Unhandled AttributeError on non-dict JSON in `visibility.py`
- **File & Line**: `visibility.py:38`
- **Impact**: If `hidden_store.json` is corrupted or written as a non-dict JSON document, `visibility._read()` crashes with `AttributeError` instead of falling back to default empty state.
- **Fix**: Added explicit `isinstance(data, dict)` check after `json.load`.

### [Medium][Bug] Unhandled AttributeError on non-dict state in `server.py`
- **File & Line**: `server.py:507`
- **Impact**: If `gateway_state.json` is written as a non-dict JSON array, `server.get_hermes_status()` crashes with `AttributeError` when accessing `state.get('pid')`.
- **Fix**: Added explicit `isinstance(state, dict)` check after reading state file.
