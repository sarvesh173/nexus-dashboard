# Sentinel Audit Report - 2026-10-21

## Summary
Resolved dynamic environment path resolution and eliminated hardcoded home directory paths across `paths.py`, `live_sync.py`, `model_health.py`, and `hermes_gateway.py`.

## Finding Details
- **File & Line**: `paths.py:15`, `live_sync.py:31-32`, `model_health.py:141`, `hermes_gateway.py:20`
- **Issue Type**: BUG / IMPROVEMENT
- **Severity**: Medium
- **Confidence**: High

### Description
1. `paths.py` evaluated `HERMES_HOME` and `OMNIROUTE_HOME` once at module import time and used them across helper functions (`hermes_env_path`, `hermes_gateway_state_path`, `hermes_logs_dir`, `hermes_profiles_dir`, `omniroute_env_path`, `omniroute_storage_path`). When applications or scripts updated `os.environ['HERMES_HOME']` or `os.environ['OMNIROUTE_HOME']` at runtime, the helper functions returned stale paths pointing to the initial default location.
2. `live_sync.py` hardcoded `os.path.join(os.path.expanduser("~"), ".hermes", "config.yaml")` and `os.path.join(os.path.expanduser("~"), ".omniroute", ".env")` as module constants `HERMES_CONFIG` and `OMNIROUTE_ENV`, ignoring `HERMES_CONFIG`, `HERMES_HOME`, and `OMNIROUTE_HOME` environment overrides entirely.
3. `model_health.py` bound `CONFIG_PATH = hermes_config_path()` at import time, preventing runtime `HERMES_CONFIG` overrides from being picked up in `_api_key()`.
4. `hermes_gateway.py` bound `ENV_FILES = (hermes_env_path(),)` at import time, preventing runtime `HERMES_HOME` updates from taking effect when locating the gateway API key.

### Verification & Test Evidence
Added unit tests in `tests/test_audit_fixes.py` (`TestDynamicPathResolution`) verifying:
- `paths.py` helper functions dynamically reflect runtime modifications to `os.environ['HERMES_HOME']` and `os.environ['OMNIROUTE_HOME']`.
- `live_sync.py` resolves Hermes config and OmniRoute env paths dynamically via `paths.hermes_config_path()` and `paths.omniroute_env_path()`.
- `hermes_gateway.py` reads key from dynamic `hermes_env_path()`.
All 204 unit tests in the test suite pass cleanly.
