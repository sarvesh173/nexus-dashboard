# Sentinel Audit Report — 2026-10-25

## Summary
Audited repository for robustness, reliability, and error handling across Python backend modules and JSON store readers. Discovered multiple JSON shape assumption bugs where top-level JSON arrays or non-dict payloads in store files or HTTP request bodies caused unhandled `AttributeError` exceptions.

## Findings & Proofs

### 1. `visibility.py:38` - `AttributeError` on non-dict `hidden_store.json`
- **Severity**: High | **Confidence**: High
- **Evidence**: `visibility._read()` loaded `hidden_store.json` via `json.load(fh)` and called `data.get(k)`. When `hidden_store.json` contained a top-level array `[]` or non-dict JSON, `data.get(k)` raised `AttributeError: 'list' object has no attribute 'get'`.
- **Impact**: Completely broke visibility operations (`hidden_providers()`, `hidden_models()`, `set_hidden()`, `prune()`) and server model list filtering.
- **Fix**: Validated `if not isinstance(data, dict): data = _blank()` in `_read()`.

### 2. `hermes_gateway.py:70` - `AttributeError` on non-dict `/models` response
- **Severity**: Medium | **Confidence**: High
- **Evidence**: `list_models()` evaluated `data.get('data', [])`. If the gateway returned a top-level list `[{"id": "..."}]` or non-dict JSON, `data.get` raised `AttributeError`.
- **Impact**: Failed `list_models()` and set `_cache['error']`, degrading catalog resolution on non-dict gateway responses.
- **Fix**: Adopted `models_payload.model_rows(data)` guard inside `list_models()`.

### 3. `model_health.py:100` - `AttributeError` when `model_health.json` has non-dict `models` field
- **Severity**: Medium | **Confidence**: High
- **Evidence**: `_load()` used `_registry.setdefault('models', {})`. If disk JSON contained `{"models": []}`, `setdefault` returned `[]`. Subsequent calls to `get_health_map()`, `is_hidden()`, `sync_models()`, and `summary()` invoked `.items()`, `.get()`, or `.values()` on `models`, raising `AttributeError`.
- **Impact**: Crashed model health map resolution and auto-hide logic on corrupt or non-dict `models` store.
- **Fix**: Enforced `if not isinstance(_registry.get('models'), dict): _registry['models'] = {}` and added dict type guards for records in health helpers.

### 4. `assign_icons.py:137` - `AttributeError` on non-dict `live_sync.json` cache
- **Severity**: Low | **Confidence**: High
- **Evidence**: `build()` loaded `live_sync.json` and immediately invoked `cache.pop("_meta", None)` and `cache.items()`. If `live_sync.json` contained a top-level JSON list `[]`, `cache.pop` raised `AttributeError`.
- **Impact**: The icon assignment script crashed when encountering non-dict cache payloads.
- **Fix**: Added `isinstance(cache, dict)` and `isinstance(prov, dict)` shape guards before iterating.

### 5. `server.py:507,1759,1885,1901` - `AttributeError` on non-dict request bodies and `gateway_state.json`
- **Severity**: Medium | **Confidence**: High
- **Evidence**: HTTP POST handlers (`/api/model/test`, `/api/model/active`, `/api/visibility`) called `body = json.loads(...)` and immediately evaluated `body.get(...)`. A non-dict JSON request body (e.g. `[1, 2, 3]`) raised unhandled `AttributeError` resulting in 500 Internal Server Errors. Similarly, `get_hermes_status()` evaluated `state.get('pid')` on `state = json.load(fh) or {}`, which raised `AttributeError` if `gateway_state.json` contained a list or primitive.
- **Impact**: API endpoints crashed with 500 server errors on valid non-dict JSON request bodies, and gateway status crashed on non-dict state files.
- **Fix**: Added `isinstance(body, dict)` validation in POST handlers returning HTTP 400 bad request, and guarded `state` in `get_hermes_status()`.
