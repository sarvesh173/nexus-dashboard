# Sentinel Audit Report - 2026-10-22

## [high][bug] Uncaught AttributeError when `hermes_gateway.list_models` parses non-standard `/models` responses

* **Summary**: `hermes_gateway.list_models()` assumed the JSON body returned by `/models` was always a dictionary containing a `"data"` key holding a list of dictionaries. Parsing occurred outside the `try...except` block, causing uncaught `AttributeError` exceptions when `/models` returned a top-level JSON array (`[...]`) or non-dictionary list items (e.g. `None` or string).
* **Evidence**: `hermes_gateway.py:67` - `ids = sorted({m.get('id') for m in data.get('data', []) if m.get('id')})`.
* **Impact**: Caused uncaught crashes on `/models` catalog calls (`list_models()`, `catalog()`, `status()`) when connected to endpoints or proxies returning array payloads or malformed rows.
* **Suggested Fix**: Use `models_payload.model_rows(data)` inside the `try...except` block to safely normalize array and dictionary responses into valid model rows.
* **Confidence**: High (100% reproducible and verified via unit tests).
