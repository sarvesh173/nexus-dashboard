# Sentinel Audit Report — 2026-10-14

## Findings

### 1. `[HIGH][BUG]` `server.py`: `AttributeError` when OpenRouter returns `"top_provider": null`
- **Location**: `server.py:1974` (inside `/api/model/context` route)
- **Impact**: When OpenRouter returns a model item with `"top_provider": null`, calling `item.get('top_provider', {}).get('max_completion_tokens')` evaluated `item.get('top_provider', {})` to `None` (because the key was present in the dictionary with value `None`), and then called `.get(...)` on `None`, raising `AttributeError: 'NoneType' object has no attribute 'get'`. This broke the `/api/model/context` route response and caused a 500 error.
- **Evidence**: Reproduced via unit test with OpenRouter payload `{"data": [{"id": "openai/gpt-4o", "context_length": 128000, "top_provider": null}]}`.
- **Fix**: Replaced direct `.get(...)` chain with `(item.get('top_provider') or {}).get('max_completion_tokens')`.
- **Confidence**: High

### 2. `[MED][RELIABILITY]` `tests/test_dashboard_mounts.py` & `tests/test_model_connection.py`: Ununittestable module import & connection failure
- **Location**: `tests/test_dashboard_mounts.py:9` and `tests/test_model_connection.py:12`
- **Impact**: Running standard Python test discovery (`python3 -m unittest discover -s tests`) crashed with 3 test errors because `test_dashboard_mounts.py` executed Playwright navigation at module top-level on import (which failed with `ERR_CONNECTION_REFUSED` when the dev server was offline) and `test_model_connection.py` attempted connection to `127.0.0.1:5174` without launching a test server.
- **Fix**: Wrapped top-level Playwright execution in `test_dashboard_mounts.py` inside `if __name__ == "__main__":` and added `setUpClass` / `tearDownClass` background server initialization to `test_model_connection.py`.
- **Confidence**: High
