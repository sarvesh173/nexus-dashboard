# Sentinel Finding Report (2026-10-14)

## [med][reliability] Test coverage for optional yaml module guards in server.py

### Summary
When `yaml` is missing (`yaml = None`), functions in `server.py` (`_hermes_active_model`, `config_provider_map`, `get_all_config_providers`) handle `yaml is None` with `if yaml is not None` checks. However, regression tests were missing to verify that these functions execute cleanly when `yaml` is `None`.

### Evidence
- File: `server.py:421`, `server.py:913`, `server.py:1409`, `server.py:1609`
- Repro: Run unit tests with `yaml` mocked as `None`.

### Impact
Ensures reliability and prevents potential unhandled `AttributeError` when `yaml` is not installed in the environment.

### Suggested Fix / Verification
Added `test_server_yaml_is_none_guards` in `tests/test_audit_fixes.py` which mocks `yaml` as `None` and calls `server._hermes_active_model()`, `server.config_provider_map()`, and `server.get_all_config_providers()`.

### Confidence
High
