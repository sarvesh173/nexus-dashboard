# Sentinel Audit Report - 2026-10-13

## Summary
Found and resolved `AttributeError` bugs in `server.py` where optional modules `psutil` and `requests` are set to `None` on systems where they are not installed, but subsequent functions called methods or properties on them without checking `if psutil is not None` or `if requests is not None`.

## Finding Details
- **File & Line**: `server.py:513`, `server.py:938`, `server.py:1769`, `server.py:1961`
- **Issue Type**: BUG / RELIABILITY
- **Severity**: High
- **Confidence**: High

### Description
In `server.py`, `psutil` and `requests` are imported in fallback `try...except ImportError` blocks setting `psutil = None` and `requests = None` if the third-party libraries are missing.
However:
1. `get_hermes_status()` attempted `psutil.Process(pid)` whenever a valid integer PID was found in `gateway_state.json`. If `psutil` was not installed, this raised `AttributeError: 'NoneType' object has no attribute 'Process'`.
2. `get_hermes_config_providers()` called `requests.get()` when inspecting NVIDIA provider endpoints.
3. `/api/model/test` handling called `requests.post()` and referenced `requests.exceptions.Timeout`.
4. `/api/model/context` handling called `requests.get("https://openrouter.ai/...")`.

### Verification & Test Evidence
Added unit tests in `tests/test_audit_fixes.py` (`TestServerOptionalImportsGuard`) that simulate environments where `psutil` or `requests` is `None`. Confirmed that without the guard, calling `get_hermes_status()` raises `AttributeError: 'NoneType' object has no attribute 'Process'`. With guards in place, all functions run cleanly and report appropriate status (`alive: False` / status `Unavailable` / status `503`).
