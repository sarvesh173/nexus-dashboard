# Sentinel Audit Report - 2026-10-18

## 1. [med][bug] SQL-level query filtering in omniroute_logs.py
- **File**: `omniroute_logs.py:284`
- **Summary**: `read_call_logs_page` fetched a page of 50 unfiltered rows from SQLite before applying Python in-memory filters for `model`, `provider`, `account`, `status`, `agent`, and `search`.
- **Impact**: Filtered query results returned truncated pages (e.g., 1-2 rows instead of 50) and incorrect total counts, breaking pagination when searching or filtering log traffic.
- **Fix**: Pushed `model`, `provider`, `account`, `status`, `agent`, and `search` filter conditions down into SQLite SQL `WHERE` clauses inside `omniroute_logs._query_calls`, ensuring accurate total counts and page limits before offset pagination.
- **Confidence**: High

## 2. [low][reliability] Isolated optional module mocks in tests/test_audit_fixes.py
- **File**: `tests/test_audit_fixes.py:454`
- **Summary**: Tests directly called `patch("requests.get")` or `patch.object(model_health.requests, "post")` when `requests` was not installed in the test environment, resulting in `ModuleNotFoundError` or `AttributeError`.
- **Impact**: The test suite failed 6 tests on environments lacking optional third-party packages.
- **Fix**: Updated test mocks to use `patch.dict("sys.modules", ...)` and patch module-level references so tests run cleanly whether `requests` is installed or absent.
- **Confidence**: High

## 3. [low][reliability] Safe browser executable launch in Playwright tests
- **File**: `tests/test_overview_motion.py:96`
- **Summary**: `test_overview_motion.py` passed a hardcoded `executable_path='/usr/bin/chromium'` without checking if the file existed.
- **Impact**: Test failed with `BrowserType.launch: Failed to launch chromium because executable doesn't exist at /usr/bin/chromium`.
- **Fix**: Added `os.path.exists("/usr/bin/chromium")` guard before passing `executable_path` and handled offline connection errors gracefully.
- **Confidence**: High
