# Sentinel Audit Findings - 2026-10-20

## Finding 1: Unhandled Array Payload in Hermes Gateway Model List
- **Severity**: High
- **Type**: Bug
- **Confidence**: High
- **File**: `hermes_gateway.py:73`
- **Summary**: `hermes_gateway.list_models()` directly evaluated `data.get('data', [])` on `/models` JSON output. When a gateway or proxy answered with a top-level JSON list (`[...]`) or non-dict items, `data.get()` raised an `AttributeError`. The outer `try...except` caught this exception, recorded `_cache['error'] = "AttributeError: 'list' object has no attribute 'get'"`, and returned an empty list `[]`.
- **Fix**: Updated `list_models()` to use the shared `model_rows(data)` helper from `models_payload.py` to normalise dictionary and array responses safely.

## Finding 2: Hardcoded Home Directory Paths in Live Sync Engine
- **Severity**: Medium
- **Type**: Bug
- **Confidence**: High
- **File**: `live_sync.py:99`
- **Summary**: `live_sync.py` imported `hermes_config_path` and `omniroute_env_path` from `paths.py` but used module-level hardcoded home-directory fallback strings (`HERMES_CONFIG`, `OMNIROUTE_ENV`), bypassing `paths.py` and ignoring environment variable overrides (`HERMES_CONFIG`, `HERMES_HOME`, `OMNIROUTE_HOME`).
- **Fix**: Updated `fetch_hermes_config()` and `omniroute_endpoint()` in `live_sync.py` to call `hermes_config_path()` and `omniroute_env_path()`, and removed the redundant hardcoded path constants.
