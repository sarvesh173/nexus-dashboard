# Sentinel Audit Report - 2026-10-20

## Summary
Fixed an unhandled `AttributeError` in `hermes_gateway.py` when the gateway `/models` endpoint returns a top-level JSON array or non-dictionary response.

## Finding
- **File**: `hermes_gateway.py:73`
- **Severity**: High
- **Confidence**: High
- **Impact**: When the upstream gateway endpoint returns a top-level JSON list (e.g., `[{"id": "model-1"}]`) or non-dictionary JSON response instead of `{"data": [...]}` dictionary format, `data.get('data', [])` raises `AttributeError: 'list' object has no attribute 'get'`, causing catalog fetches and gateway status checks to fail or crash unexpectedly.
- **Fix**: Replaced direct `.get('data', [])` call on `data` with the project's shared `model_rows(data)` payload shape guard from `models_payload.py`.
- **Evidence**: `list_models()` raised `AttributeError: 'list' object has no attribute 'get'` when `_get('/models')` returned a JSON array. Regression tests in `tests/test_audit_fixes.py` confirm correct parsing across diverse response shapes.
