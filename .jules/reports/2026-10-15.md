# Sentinel Audit Report - 2026-10-15

## Summary
Fixed test discovery failures in `tests/test_model_connection.py` and `tests/test_dashboard_mounts.py` when executing `python3 -m unittest discover tests/`.

## Findings

### Finding 1: Unhandled ConnectionRefusedError in `tests/test_model_connection.py` during unit test runner discovery
- **Severity**: Medium
- **Type**: Reliability / Test Suite
- **Location**: `tests/test_model_connection.py:7`
- **Description**: `test_model_connection.py` assumed a local server was already running on port 5174. When running standard unit tests via `python3 -m unittest discover`, requests threw `URLError: <urlopen error [Errno 111] Connection refused>`.
- **Fix**: Added `setUpClass` and `tearDownClass` hooks to start and stop a local `server.TelemetryHandler` instance on an ephemeral port during test execution.

### Finding 2: Unguarded top-level script execution in `tests/test_dashboard_mounts.py`
- **Severity**: Low
- **Type**: Reliability / Test Suite
- **Location**: `tests/test_dashboard_mounts.py:11`
- **Description**: `test_dashboard_mounts.py` executed Playwright browser launching and HTTP page navigation at top-level import scope without `if __name__ == '__main__':` guards, causing test discovery (`unittest discover`) to fail when no local web server was running.
- **Fix**: Wrapped the top-level Playwright execution inside a `main()` function guarded by `if __name__ == '__main__':`.
