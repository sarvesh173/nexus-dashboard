# Sentinel Audit Report — 2026-10-15

## Summary
- **Title**: `[high][bug] Optional requests dependency mocking in test_audit_fixes raises ModuleNotFoundError / AttributeError when requests absent`
- **Severity**: High
- **Confidence**: High
- **Impact**: Unit tests in `tests/test_audit_fixes.py` fail with 6 errors when `requests` is absent/uninstalled, blocking automated test suites in offline or lean environments.

## Evidence
- Running `python3 -m unittest discover -s tests` without `requests` installed raised:
  1) `ModuleNotFoundError: No module named 'requests'` on `TestLiveSpecsNon200IsLoud` due to direct `patch("requests.get")`.
  2) `AttributeError: None does not have the attribute 'post'` on `TestProbeUrlJoin` due to `patch.object(model_health.requests, 'post')` when `model_health.requests` is `None`.

## Fix
- In `tests/test_audit_fixes.py`:
  - Updated `TestLiveSpecsNon200IsLoud` to use `patch.dict("sys.modules", {"requests": fake_req})`.
  - Updated `TestProbeUrlJoin` to pass a mock object and patch `model_health.requests` and `sys.modules["requests"]`.
  - Updated `TestOpenRouterTopProviderNull` to use `patch.object(server, "requests", mock_req)`.
