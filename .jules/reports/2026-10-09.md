# Sentinel Audit Report — 2026-10-09

## Findings

### [med][reliability] Mismatched `package-lock.json` and `package.json` causes `npm ci` failures in CI workflows

- **Summary**: The `package-lock.json` in the repository is out of sync with `package.json`, causing GitHub Actions CI workflows running `npm ci` to fail with `EUSAGE`.
- **Evidence**: GitHub Actions workflow step `Run npm ci` failed with:
  `npm error 'npm ci' can only install packages when your package.json and package-lock.json or npm-shrinkwrap.json are in sync. Please update your lock file with 'npm install' before continuing.`
  `npm error Missing: @tailwindcss/vite@4.3.3 from lock file`
  `npm error Missing: oxlint@1.87.0 from lock file`
  `npm error Missing: react-router-dom@7.18.4 from lock file`
- **Impact**: All automated verification CI workflows fail on pull requests and commits during the `npm ci` setup step.
- **Suggested Fix**: Run `npm install` locally to update `package-lock.json` and commit the updated lockfile in a dedicated dependency update PR or issue fix.
- **Confidence**: High
- **Severity**: Medium
