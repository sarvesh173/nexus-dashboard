# Sentinel Audit Report — 2026-10-11

## Findings Summary

### 1. [med][reliability] Optional third-party packages (`psutil`, `yaml`, `requests`) cause import-time `ModuleNotFoundError`

- **File**: `server.py:3-10`, `model_health.py:26`, `run_sync.py:27-28`
- **Type**: Reliability / Error Handling
- **Severity**: Medium
- **Confidence**: High
- **Description**: Top-level imports for `psutil`, `yaml`, and `requests` were not guarded with `try...except ImportError`. Environments without these packages crashed upon importing backend modules rather than safely falling back or reporting degraded capabilities.
- **Fix**: Wrapped imports in `try...except ImportError` and added safe fallbacks across telemetry and sync functions.

---

### 2. [high][build] `package-lock.json` is out of sync with `package.json` causing CI `npm ci` failure

- **File**: `package-lock.json`, `package.json`
- **Type**: Build / CI
- **Severity**: High
- **Confidence**: High
- **Description**: Running `npm ci` in GitHub Actions fails with `npm error 'npm ci' can only install packages when your package.json and package-lock.json or npm-shrinkwrap.json are in sync`. Missing entries in lockfile include `@tailwindcss/vite`, `oxlint`, `react-router-dom`, and `typescript`.
- **Suggested Fix**: Run `npm install` on the main branch to update `package-lock.json`. Per Sentinel rules, lockfiles are not modified directly in Sentinel PRs.
