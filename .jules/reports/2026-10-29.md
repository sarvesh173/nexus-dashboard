# Sentinel Audit Report — 2026-10-29

## Findings Summary

### [med][bug] Hardcoded home paths and static import-time env evaluation in live_sync.py and paths.py
- **Summary**: `live_sync.py` hardcoded `HERMES_CONFIG` and `OMNIROUTE_ENV` paths to `~/.hermes/config.yaml` and `~/.omniroute/.env`, ignoring environment variable overrides. Furthermore, `paths.py` evaluated `HERMES_HOME` and `OMNIROUTE_HOME` once at module import time, preventing dynamic environment variable overrides during runtime execution and testing.
- **Evidence**: `live_sync.py:31`, `paths.py:9`
- **Impact**: Deployments or automated test runs using environment variables like `HERMES_HOME`, `HERMES_CONFIG`, or `OMNIROUTE_HOME` failed to locate configuration files and proxy environments, causing fallback or catalog sync failures.
- **Suggested Fix**: Use helper functions in `paths.py` that evaluate `os.environ` dynamically at call time, and update `live_sync.py` to use `hermes_config_path()` and `omniroute_env_path()`.
- **Confidence**: High
- **Severity**: Medium
