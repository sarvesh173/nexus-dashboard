# Sentinel Audit Report — 2026-10-08

## [HIGH][BUG] Unit test failures when optional `requests` module is missing

- **Summary**: `tests/test_audit_fixes.py` crashed with `ModuleNotFoundError` or `AttributeError` when running `npm test` without the optional `requests` package installed.
- **Evidence**: `tests/test_audit_fixes.py:454` and `tests/test_audit_fixes.py:657`
- **Impact**: Test suite execution (`npm test`) failed in environments where optional HTTP dependencies were not installed, despite backend code properly handling missing dependencies.
- **Suggested Fix**: Mock optional dependencies via `patch.dict("sys.modules", ...)` or `patch.object` on the module level rather than calling `patch("requests.get")` directly.
- **Confidence**: High

## [MED][RELIABILITY] Hardcoded browser path and uncaught connection errors in Playwright tests

- **Summary**: `tests/test_overview_motion.py` hardcoded `/usr/bin/chromium` and Playwright test scripts crashed with uncaught `net::ERR_CONNECTION_REFUSED` when the local dev server was offline.
- **Evidence**: `tests/test_overview_motion.py:96` and `tests/test_nav_animations.py:45`
- **Impact**: `npm test` failed in CI / offline test environments when local dev server (`http://localhost:5173`) was not running or Chromium was installed under alternate system paths.
- **Suggested Fix**: Use fallback resolution for browser binary paths and catch connection exceptions gracefully during `page.goto`.
- **Confidence**: High
