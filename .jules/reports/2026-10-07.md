# Sentinel Audit Report — 2026-10-07

## Findings Summary

### Finding 1: Unhandled `ModuleNotFoundError` on optional `psutil` dependency in `server.py`
* **Severity**: High
* **Confidence**: High
* **Type**: Bug / Reliability
* **Location**: `server.py:3`
* **Evidence**: Running unit tests in an environment without `psutil` installed raised `ModuleNotFoundError: No module named 'psutil'` at module import time, causing test suite failures across multiple test modules (`test_omniroute_logs.py`, `test_server_nvidia.py`).
* **Impact**: Backend server crashes on startup in minimal environments lacking `psutil` or during headless test execution.
* **Fix Applied**: Wrapped `import psutil` in a `try...except ImportError` block in `server.py`, provided structured fallback telemetry values when `psutil` is unavailable, and added in-process HTTP server initialization to `tests/test_model_connection.py`.

### Finding 2: Missing CSS stylesheet `src/styles/tokens.css` breaking Vite build
* **Severity**: High
* **Confidence**: High
* **Type**: Bug / DX
* **Location**: `src/index.css:2`
* **Evidence**: `src/index.css` references `@import "./styles/tokens.css";` and `tests/test_tokens_m3.py` verifies M3 design tokens against `src/styles/tokens.css`. When the file is missing from disk, `npm run build` fails with `Error: Can't resolve './styles/tokens.css' in '/app/src'`.
* **Impact**: Production frontend build (`npm run build`) fails completely.
* **Suggested Fix**: Restore `src/styles/tokens.css` with the required Material Design 3 (M3) design tokens (`--md-sys-color-*`, `--md-sys-shape-corner-*`, `--md-sys-typescale-*`, `--md-sys-elevation-level*`, `--md-sys-state-*`) and theme declarations (`indigo-violet`, `obsidian-emerald`, `cyberpunk-neon`, `industrial-amber`, `paper-light`).
