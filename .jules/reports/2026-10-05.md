# Sentinel Finding Report - 2026-10-05

## [HIGH][BUG] AttributeError when optional `requests` dependency is missing

- **Summary**: `server.py`, `model_health.py`, and `run_sync.py` import `requests` inside a `try...except ImportError` block and set `requests = None` if missing, but then invoke `requests.get()`, `requests.post()`, `requests.Timeout`, and `requests.exceptions.Timeout` directly without checking if `requests is not None`.
- **Evidence**:
  - `run_sync.py`: `requests.get` called directly when fallback spec retrieval runs.
  - `model_health.py`: `_probe()` catches `requests.Timeout`, which raises `AttributeError: 'NoneType' object has no attribute 'Timeout'` when `requests` is `None`.
  - `server.py`: `requests.get` and `requests.post` called directly in `/api/model/test`, `/api/model/context`, and `get_hermes_config_providers()`.
- **Impact**: Server/sync crashes with `AttributeError` in minimal Python environments without `requests` installed.
- **Suggested fix**: Guard calls with `if requests is not None:` and handle timeouts using generic exception inspection (`'Timeout' in type(exc).__name__`).
- **Confidence**: High
