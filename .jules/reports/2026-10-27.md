# Sentinel Finding Report (2026-10-27)

## Finding 1
- **Title**: `[high][bug] hermes_gateway.list_models crashes on top-level JSON array response`
- **Severity**: high
- **Type**: bug
- **File & Line**: `hermes_gateway.py:72`
- **Summary**: `hermes_gateway.list_models` assumed `/v1/models` responses are always dictionaries with a `"data"` field and evaluated `data.get("data", [])`. When the upstream gateway or proxy responds with a top-level JSON array (`[{...}]`), `.get()` raised an unhandled `AttributeError: 'list' object has no attribute 'get'`.
- **Impact**: Breaks `hermes_gateway.list_models()`, `catalog()`, and `status()`, causing the live models gateway catalog to crash and status reporting to fail.
- **Evidence**:
  ```
  AttributeError: 'list' object has no attribute 'get'
  ```
  Running `hermes_gateway.list_models()` when `_get()` returned a top-level `list` crashed before the fix.
- **Suggested Fix**: Use `models_payload.model_rows(data)` to safely handle both dict and list response shapes and filter out invalid rows.
- **Confidence**: High
