## [high][bug] Missing top-level imports exception handling in server.py & model_health.py
- **File & Line**: `server.py:3`, `model_health.py:26`, `run_sync.py:27`
- **Summary**: `server.py`, `model_health.py`, and `run_sync.py` unconditionally imported `psutil`, `requests`, or `yaml` at module load time. In standard Python environments where these packages were not pre-installed, importing any of these modules raised `ModuleNotFoundError`, crashing `python3 -m unittest` and preventing background sync / telemetry endpoints from functioning.
- **Impact**: Server endpoints failed with uncaught exceptions when dependencies were absent; unit test suite failed when loading test modules importing `server` or `model_health`.
- **Suggested Fix**: Wrap `psutil`, `requests`, and `yaml` imports in `try...except ImportError` blocks and provide clean fallback structures (`_Zero` for psutil metrics, missing-library status strings for probe requests, etc.).
