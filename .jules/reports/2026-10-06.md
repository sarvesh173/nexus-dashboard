# Sentinel Report 2026-10-06

## [high][bug] Missing third-party dependencies crash backend server and model sync modules

- **Summary**: `server.py`, `model_health.py`, and `run_sync.py` unconditionally imported optional third-party Python packages (`psutil`, `requests`, `yaml`) at top-level. In standard Python runtime environments missing these packages, importing or executing backend functions raised `ModuleNotFoundError`, taking down telemetry and model synchronization endpoints.
- **Evidence**:
  - `server.py:3`: `import psutil` raised `ModuleNotFoundError: No module named 'psutil'` during `python3 -m unittest`.
  - `model_health.py:26`: `import requests` raised `ModuleNotFoundError: No module named 'requests'`.
  - `tests/test_model_connection.py` and `tests/test_dashboard_mounts.py` crashed when target test ports were unreachable during discovery.
- **Impact**: Backend server failed to start or serve telemetry data and model testing requests in minimalist environments without optional packages installed.
- **Suggested Fix**: Wrap optional imports in `try/except ImportError` blocks and implement standard-library fallbacks using `urllib.request`, `/proc/meminfo`, `os.statvfs`, and JSON parsing. Handle connection failures in unit test discovery using `unittest.SkipTest`.
- **Confidence**: High
