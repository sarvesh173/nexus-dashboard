# Sentinel Audit Report — 2026-10-04

## Findings

### [high][bug] Unhandled NameError in `run_sync.py` when NVIDIA API key is configured

- **Summary**: `run_sync.fetch_specs()` calls `hermes_config_path()` which was not imported from `paths.py`.
- **Evidence**: `run_sync.py:34` calls `with open(hermes_config_path()) as fh:`. Running `run_sync.fetch_specs()` with `model_health._api_key()` returning an API key raises `NameError: name 'hermes_config_path' is not defined`.
- **Impact**: Model-health sync background runner fails immediately upon detecting an API key in configuration, preventing health sync updates.
- **Suggested Fix**: Import `hermes_config_path` from `paths.py` in `run_sync.py`.
- **Confidence**: High
- **Severity**: High
