# Sentinel Audit Report — 2026-10-24

## Findings

### 1. [med][bug] Static import-time evaluation of configuration and environment paths
- **Summary**: `paths.py`, `live_sync.py`, `model_health.py`, and `hermes_gateway.py` evaluated configuration paths (`HERMES_HOME`, `HERMES_CONFIG`, `OMNIROUTE_HOME`, `ENV_FILES`) into import-time module constants. Setting `os.environ["HERMES_HOME"]`, `os.environ["HERMES_CONFIG"]`, or `os.environ["OMNIROUTE_HOME"]` at runtime after module import was ignored during execution.
- **Evidence**: `paths.py:10` evaluated `HERMES_HOME` once at import time. Calling `hermes_env_path()` or `live_sync.fetch_hermes_config()` after updating `os.environ` returned the original path calculated at import time.
- **Impact**: Runtime environment overrides (e.g. multi-tenant setups, CLI wrappers, test suites, or dynamic daemon re-configurations) failed to take effect.
- **Suggested Fix**: Convert path functions to query `os.environ` dynamically at call time and use module `__getattr__` for constant attribute access backward compatibility.
- **Confidence**: High.
